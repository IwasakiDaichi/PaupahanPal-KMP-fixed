# PaupahanPal KMP Starter

This source starter uses the module names from the provided Android Studio screenshot: `shared`, `androidApp`, and `desktopApp`. The shared module also defines iOS framework targets for an existing `iosApp` Xcode project.

## Open
Open the folder containing `settings.gradle.kts` in Android Studio, then sync Gradle.

## iOS
The `shared` module produces a framework named `Shared`. Your existing Xcode project must link this framework using the integration generated by your original KMP template. The native `iosApp` folder is not replaced by this ZIP.

## Included UI
Dashboard, rooms, rent ledger, payment entry, repairs, tenant timeline notes, follow-ups, and bottom navigation.

## Prototype limitations
Data is held in memory and resets on restart. This is not production-ready and does not yet implement authentication, database persistence, photo uploads, notification scheduling, or full itemized payment history. iOS builds require macOS and Xcode.

## Compatibility
This uses Kotlin 2.1.21, Compose Multiplatform 1.8.2, and Android Gradle Plugin 8.9.2 as a consistent starter baseline. If your existing project uses different versions, reconcile the version catalog and generated platform integration before replacing your existing Gradle files.
